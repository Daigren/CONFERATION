# Conferation

Веб-приложение для подачи и рассмотрения заявок на участие в конференциях (React + Vite).

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173. Сборка для публикации: `npm run build` (результат в `dist/`).

## Демонстрационные учётные записи

Создаются автоматически при первом запуске:

| Роль | E-mail | Пароль |
| --- | --- | --- |
| Администратор | admin@conferation.ru | admin123 |
| Участник | ivanov@example.com | user123 |
| Участник | petrova@example.com | user123 |
| Участник | sidorov@example.com | user123 |

Чтобы сбросить данные, очистите хранилище сайта в браузере (DevTools → Application → Clear site data).

## Страницы (ТЗ, таблица 6)

| Страница | Адрес | Доступ |
| --- | --- | --- |
| Регистрация | `/register` | все |
| Авторизация | `/login` | все |
| Страница пользователя | `/cabinet` | участник |
| Подача / доработка заявки | `/apply`, `/apply/:id` | участник |
| Страница администратора | `/admin` (вкладки «Заявки» и «Конференции»), конструктор `/admin/conferences/:id` | администратор |
| Рассмотрение заявки | `/admin/applications/:id` | администратор |

## Устройство

- `src/api/index.js` — бизнес-логика: регистрация, авторизация, конструктор конференций, подача,
  доработка и модерация заявок, статусная модель (ТЗ, таблица 3).
- `src/api/db.js` — хранилище записей (пользователи, конференции, заявки, статусы, комментарии)
  в `localStorage`. Изменения из других вкладок приходят через событие `storage`, поэтому
  кабинет и панель администратора обновляются в реальном времени.
- `src/api/files.js` — файловое хранилище документов в IndexedDB; при открытии и скачивании
  проверяется целостность (размер файла).
- `src/api/template.js` — типовая матрица полей и документов по ролям (приложение А).

Серверной части нет: весь слой данных изолирован в `src/api`, его можно заменить на вызовы
REST API, не трогая страницы.
